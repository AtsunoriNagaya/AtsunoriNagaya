## About

<p align="center">
I build web apps with LLMs inside, end to end: a Next.js front end, a Python or Node back end, and a deployment on Vercel, AWS or Firebase.<br />
Recent work covers retrieval over past documents (RAG), switching between OpenAI, Anthropic and Gemini behind one interface, and classic ML with scikit-learn.
</p>

<p align="center">
LLM を組み込んだ Web アプリを、フロントエンドからバックエンド、デプロイまで一通り作っています。<br />
RAG、複数の LLM プロバイダの切り替え、scikit-learn を使った機械学習も扱います。
</p>
